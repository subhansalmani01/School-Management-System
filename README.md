# School-Management-System
<h1>School-Management-System</h1>

https://subhansalmani01.github.io/School-Management-System/


A comprehensive web application designed to streamline the management of school operations. This project enables administrators to efficiently manage student records, faculty information, course registrations, and more, all within a user-friendly interface.

## Features

- Student & Teacher Management
- Attendance & Grading
- Secure Login & Dashboard

## Tech Stack

- HTML, CSS, JavaScript
- PHP & MySQL

## Installation

1. Clone the repo:
   ```sh
   https://github.com/subhansalmani01/School-Management-System
   ```
2. Import the database in **phpMyAdmin**.
3. Configure `connection.php`.
4. Start the server & open `http://localhost/school-management-system/`

## Usage

- **Admin:** Manage records.
- **Teacher:** Update courses & grades.
- **Student:** View records.
